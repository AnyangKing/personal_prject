1. 표지

안녕하세요. 저는 일본어 초급 학습자를 위한 웹앱, 일본어 마스터 AI를 개발했습니다.

이 앱은 단순히 히라가나와 가타카나를 외우는 데서 끝나는 것이 아니라, 문자 학습, 퀴즈, 학습 통계, 그리고 AI를 활용한 표현 생성과 대화 연습까지 한 흐름으로 이어지도록 만든 일본어 학습 서비스입니다.

핵심은 "일본어를 외우는 앱"이 아니라, 일본어를 실제로 써보게 만드는 앱입니다.


2. 개발 배경 / 문제 정의

제가 이 앱을 만들게 된 이유는 기존 일본어 학습 방식에서 조금 아쉬운 부분을 느꼈기 때문입니다.

대부분의 초급 학습 앱은 히라가나 표를 보여주거나, 단어장을 제공하거나, 단순한 퀴즈를 반복하는 방식이 많습니다. 물론 기초를 익히는 데는 도움이 되지만, 학습자가 실제 상황에서 "이걸 어떻게 말하지?"라는 단계로 넘어가면 연결이 약해지는 경우가 많습니다.

또 퀴즈를 풀어도 내가 어떤 글자에 약한지, 어떤 범위를 더 연습해야 하는지 누적해서 보여주는 기능이 부족하다고 느꼈습니다.

그래서 저는 기초 문자 학습과 반복 퀴즈에 AI를 연결해서, 학습자가 자기 상황에 맞는 표현을 만들고 실제 대화처럼 연습할 수 있는 구조를 목표로 했습니다.


3. 시스템 구조

시스템 구조는 크게 세 부분으로 나누었습니다.

첫 번째는 사용자가 직접 실행하는 HTML 단일 파일 앱입니다. 화면 구성, 퀴즈, 커리큘럼, 학습 기록 저장 같은 기본 기능은 모두 이 파일 안에서 동작합니다. 별도의 복잡한 설치 없이 브라우저에서 바로 실행할 수 있게 만들었습니다.

두 번째는 Google Cloud Functions입니다. 처음에는 Gemini API 키를 HTML에 직접 넣는 방식도 생각했지만, 보안이나 크레딧 사용 측면에서 적절하지 않았습니다. 그래서 중간에 Cloud Functions를 두고, 프론트엔드는 이 함수만 호출하도록 바꿨습니다.

세 번째는 Vertex AI입니다. Cloud Functions가 Vertex AI의 Gemini 모델을 호출하고, AI 응답을 다시 앱으로 보내줍니다. 특히 AI 응답이 가끔 JSON 형식을 벗어나는 문제가 있어서, Cloud Functions에서 응답을 정규화하는 처리도 넣었습니다.

기술 스택은 HTML, CSS, JavaScript, localStorage, Web Speech API, Cloud Functions, Vertex AI를 사용했습니다.


4. 주요 기능 1 - 문자표와 발음 재생

첫 번째 주요 기능은 히라가나와 가타카나 문자표입니다.

기본 오십음도뿐 아니라 탁음, 반탁음, 요음까지 포함해서 초급자가 자주 헷갈리는 부분을 한 번에 확인할 수 있도록 구성했습니다.

각 글자를 클릭하면 Web Speech API를 이용해서 발음이 재생됩니다. 단순히 눈으로만 보는 것이 아니라, 글자와 소리를 같이 연결해서 학습할 수 있게 했습니다.

또 히라가나와 가타카나는 발음은 같지만 모양이 다르기 때문에, 비교표를 통해 두 문자를 나란히 볼 수 있게 했습니다. 초급 학습자가 "아는 글자인데 가타카나로 나오면 못 읽는" 문제를 줄이는 데 초점을 두었습니다.


5. 주요 기능 2 - 퀴즈 시스템

두 번째는 퀴즈 시스템입니다.

퀴즈는 크게 세 가지 모드로 구성했습니다. 먼저 객관식 모드는 글자를 보고 올바른 로마자 발음을 고르는 방식입니다. 가장 기본적인 확인 학습입니다.

두 번째는 타이핑 모드입니다. 사용자가 직접 로마자를 입력해야 하기 때문에, 객관식보다 기억을 더 적극적으로 꺼내는 연습이 됩니다.

세 번째는 AI 맞춤 복습 모드입니다. 사용자의 오답 기록을 바탕으로 약한 글자를 우선적으로 다시 출제하도록 설계했습니다.

그리고 퀴즈 범위도 선택할 수 있게 했습니다. 처음에는 기본 히라가나만 풀 수 있고, 이후에는 탁음과 반탁음, 요음까지 포함한 전체 범위로 확장할 수 있습니다. 그래서 학습자의 수준에 맞게 단계적으로 난이도를 올릴 수 있습니다.


6. 주요 기능 3 - AI 표현 생성기

세 번째 기능은 AI 표현 생성기입니다.

사용자가 "편의점에서 계산하기", "식당에서 주문하기", "길을 잃었을 때"처럼 상황을 입력하면, AI가 그 상황에서 실제로 사용할 수 있는 일본어 표현을 생성합니다.

각 표현은 일본어 문장, 히라가나 독음, 한국어 뜻, 그리고 간단한 발음 표기와 사용 팁으로 구성됩니다.

이 기능을 넣은 이유는 초급 학습자가 단어를 외워도 실제 상황에서 문장으로 조합하기 어려워하기 때문입니다. AI를 활용하면 사용자가 원하는 상황에 맞춰 표현을 바로 얻을 수 있고, 그 표현을 다시 발음 재생으로 들어볼 수도 있습니다.

또 AI 호출이 실패할 경우를 대비해서 오프라인 상황 DB도 준비했습니다. 그래서 네트워크나 AI 응답 문제가 생겨도 기본적인 표현 학습은 이어갈 수 있습니다.


7. 주요 기능 4 - AI 대화 시뮬레이터

네 번째는 AI 대화 시뮬레이터입니다.

이 기능은 식당, 호텔, 역, 편의점, 쇼핑, 약국, 관광안내소, 공항 같은 실제 상황을 선택하고, 그 역할에 맞춰 AI와 대화하는 기능입니다.

예를 들어 식당을 선택하면 AI가 점원 역할을 하고, 사용자는 손님처럼 답변합니다. AI는 일본어 문장과 히라가나 독음, 한국어 해석을 함께 보여줍니다.

초급 학습자 입장에서는 완전히 자유로운 회화가 부담스러울 수 있기 때문에, 힌트 버튼도 넣었습니다. "뭐라고 해야 할까요?"를 누르면 다음에 말할 수 있는 일본어 예시를 받을 수 있습니다.

이 기능은 단순 암기에서 한 단계 더 나아가, 실제 상황에 가까운 말하기 연습을 가능하게 하는 부분입니다.


8. 학습 커리큘럼 + 통계

다음은 커리큘럼과 통계 기능입니다.

앱에는 총 36단원 구조의 학습 커리큘럼이 들어 있습니다. 기본 히라가나부터 시작해서 가타카나, 기초 단어, 탁음과 요음까지 단계적으로 진행할 수 있도록 구성했습니다.

각 단원은 배우기, 연습하기, 퀴즈 풀기 흐름으로 되어 있습니다. 단원을 통과하면 완료 표시가 되고, 전체 진행률에 반영됩니다.

또 학습 지속성을 위해 XP와 레벨 시스템을 넣었습니다. 퀴즈를 풀거나 AI 기능을 사용하면 경험치가 쌓이고, 연속 학습 일수도 표시됩니다.

통계 화면에서는 총 문제 수, 정답률, 완료 단원 수, 그리고 약점 TOP 5를 확인할 수 있습니다. 학습자가 막연히 공부하는 것이 아니라, 자신의 상태를 보고 다음 학습 방향을 정할 수 있도록 했습니다.


9. 개발 과정에서 해결한 문제

개발 과정에서 가장 크게 해결한 문제와 특징은 네 가지입니다.

첫 번째는 개발 과정 자체에서 생성형 AI를 적극적으로 활용했다는 점입니다. 이 앱은 단순히 AI 기능을 넣은 결과물일 뿐만 아니라, 개발 과정에서도 Codex와 Claude 같은 생성형 AI를 협업 도구로 사용했습니다. 코드 구조를 점검하거나, 오류 원인을 찾거나, 발표 자료 구성을 다듬는 과정에서 AI와 계속 상호작용하면서 개발했습니다.

두 번째는 Vertex AI 전환입니다. 처음에는 일반 Gemini API 방식으로 구현했지만, 경진대회와 실제 운영을 고려했을 때 GCP의 무료 크레딧을 사용할 수 있는 Vertex AI 구조가 더 적합했습니다. 그래서 Cloud Functions를 중간에 두는 방식으로 바꾸었습니다.

세 번째는 AI 응답 안정화입니다. AI가 항상 제가 원하는 JSON 형식으로 응답하지는 않았습니다. 그래서 Cloud Functions에서 응답을 정규화하고, 프론트엔드에서 파싱할 수 있는 형태로 맞추는 처리를 추가했습니다.

네 번째는 퀴즈 범위 확장입니다. 처음에는 기본 히라가나 중심이었지만, 학습 앱으로서 완성도를 높이기 위해 탁음, 반탁음, 요음까지 포함하도록 확장했습니다.

이 과정에서 단순히 기능을 붙이는 것보다, 시연 중 안정적으로 동작하는 구조를 만드는 것이 중요하다는 점을 많이 배웠습니다.


10. 마무리

정리하자면, 일본어 마스터 AI는 초급 일본어 학습자가 문자부터 실제 표현까지 자연스럽게 이어서 연습할 수 있도록 만든 웹앱입니다.

기초 문자표, 퀴즈, 커리큘럼, 통계 같은 전통적인 학습 기능에 AI 표현 생성과 AI 대화 시뮬레이터를 결합했습니다.

제가 생각하는 이 앱의 핵심 가치는 AI가 단순히 답을 알려주는 것이 아니라, 학습자가 직접 말해볼 수 있는 환경을 만들어준다는 점입니다.

앞으로는 음성 인식 기반 말하기 평가나, 학습자별 난이도 자동 조절 기능까지 확장할 수 있을 것 같습니다.

이상으로 발표를 마치겠습니다. 감사합니다.
